## 怎么跑

```bash
cd experiments/book-materials
node aged-textures.js      # 生成封面材质 A-antique-leather-cover.png（512px，已定稿配方）
node page-variants.js      # 生成 5 版内页 P0~P4（512px，已定稿配方，共用同一份纸张基底）
```

`build-test-page.js` 是拼装一个"材质+文字对比度"测试页的脚本，依赖 `aged-textures.js` 额外生成的
640px 预览图（文件名后缀 `-preview.png`）。如果要重新验证文字压在材质上的可读性，
先把 `aged-textures.js` 里的 `SIZE` 改成 640、`toFile` 输出改成 `-preview.png` 后缀（跟原脚本
生成 512px 版本用同一套逻辑，只是尺寸不同），再跑 `build-test-page.js`。

## 关键坑（别重复踩）

1. **纸和皮革不是同一种生成方式**。皮革用 Worley 粒面（`buildHeight`，一颗颗鼓起来的粒），
   纸用纤维状 fBm 噪声（`buildPaperHeight`，哑光細絮感）。最早内页误用了皮革的算法，
   被站长指出"这不是纸的质感"。
2. **画布尺寸必须能被格子尺寸（cell）整除**，否则噪声网格错位会出现横向条纹瑕疵。
   `SIZE` 改动时要检查所有 `cell` 值。
3. **斑点/渍痕不能是规则的同心圆**。最早的狐斑用了 `sin` 调制产生同心圆"靶心"纹，
   站长反馈像"真菌感染"；后来的渍痕（茶渍/水渍）即使去掉同心圆也是数学意义上的正圆，
   又被反馈"太规则太新"。最终方案是给每个渍痕加**随机谐波扭曲半径 + 随机偏心**
   （见 `page-variants.js` 里 `buildRingMask` 的实现），做出手绘感的不规则轮廓。
4. **内页不要做成"发霉"**。手帐是被珍惜使用的东西，霉斑传递"腐坏被遗忘"，逻辑矛盾。
   改成了茶渍/水渍/晒痕/包浆这类"用旧"痕迹（`page-variants.js` 里的 P1~P4）。
5. **同一本书的多个页面要共用同一份基底配方**（`page-variants.js` 里 `PAPER_H` / `EDGE`
   是模块级共享变量，所有 PAGES 变体都复用它们），只在"这页发生了什么"这层做区分——
   否则多页放在一起会显得风格拼凑、割裂感强，这是站长明确提的要求。
6. **封面颗粒别调太大太规整**，容易像蛇皮/鳄鱼皮而不是牛皮，站长反馈过"不适"。
   `aged-textures.js` 里 A 版的 `cell:8, crease:0.85, domeBias:0.45` 是调整后确认满意的参数，
   改动前建议先理解这几个参数分别控制什么（粒的大小/边缘对比度/凸起程度）。
