# 笔记本封面原型（首页"翻书"改版 · 重启版）

> 这不是 `experiments/book-materials/` 的延续。那个方向（深棕牛皮革封面材质）已经被站长否决，
> 详见 `docs/HANDOFF.md` 的 v5 节。这是重新提起后的**新方向**，和旧方向唯一的共同点是"给博客做一本书"
> 这个大目标，具体做法完全不同——不再单独生成封面材质，直接复用线上已经在用的贴图。

## 现在这版是什么

站长给了 4 张市售笔记本参考图（烫金压印/皱纹皮/搭扣设计/星月图腾）+ 1 张线上截图（确认过就是
`public/img/leather-calf-v1.webp`，`.post-card` 正文区正在用的那张细腻小牛皮贴图），要求：

- 封面材质 = 那张已经上线的贴图，不用再冒险出新材质
- 参考图里"烫金压印中心图腾 + 装饰边框 + 五金件"这套结构可以借，但具体图案要换成 blog.blue 自己的语言

## 定下来的设计决策（站长确认过）

| 决策点 | 选定方案 | 为什么 |
|---|---|---|
| 封面材质 | 直接复用 `leather-calf-v1.webp` / `leather-cream-v1.webp` | 已经上线、站长认过，不用重新冒险 |
| 中心图腾 | 放大版品牌签名词标本身（`src/utils/brand.js`） | 比参考图里通用的羽毛/月亮更"独一无二"，别人抄不走 |
| 图腾质感 | **卸刻凹陷感**（深色主线 + 偏移1.6px的浅色高光副本），不是烫金 | 站长明确选的，不发亮、像盖章压进皮里 |
| 装饰边框 | 罗盘弧线 + 四角十字校准记号 + 刻度短线 | 延续"工程蓝图"语言，不用参考图里的巴洛克唐草——那套和 `README.md` 明确要避开的"暖米色+套路风"是同一类风险 |
| 五金/挂件 | 加一根烫金书签带，纯装饰、不可点击，故意避开压在签名上 | 站长确认要加，参考图3/4的搭扣/松紧带思路，但简化成不会被误认成可交互元素的丝带 |
| 缝线/粗粒羽化边 | 直接复用 `.post-card` 现成的 CSS 手法和同一个金色 `--thread` | 让封面和卡片是同一件东西的两个部位，不是另画一套视觉语言 |

## 文件

- `build-cover-prototype.js`：生成原型的脚本。直接读 `public/img/leather-calf-v1.webp` /
  `leather-cream-v1.webp`（线上正在用的图，改了这两张图之后重新跑一遍脚本，原型会跟着换）和
  `src/utils/brand.js` 的 `buildSignature`（真实品牌签名，不是画一个像的）。
  跑法：`node experiments/notebook-cover/build-cover-prototype.js`
- `cover-prototype.html`：生成结果，可以直接用浏览器打开看效果。
