# 跨页原型 + 翻页动效（首页"翻书"改版 · 步骤3局部 + 步骤5）

> 承接 `experiments/notebook-cover/README.md`（封面已定稿）。这个目录做的是
> **步骤3的最小验证**（封面+目录页放一起协不协调）和**步骤5**（点击目录条目→
> 全文页的翻页动效），跳过了步骤3剩余细节和步骤4，是站长指定的顺序，不是遗漏。

## 现在这里有什么

- `gen-page-textures.js`：内页"痕迹故事"材质生成脚本，**原样复制自**
  `experiments/book-materials/page-variants.js`（那份没被否决的部分——发霉方向被
  推翻后改成的茶渍/水渍/晒痕/包浆五变体，算法本身站长已确认过，这里只是换了个
  输出目录，没有改算法）。跑法：`node experiments/notebook-spread/gen-page-textures.js`，
  会在本目录生成 `P0-clean.png` ~ `P4-handling-patina.png` 五张贴图。
- `build-spread-prototype.js` → `spread-prototype.html`：**步骤3的最小验证**。
  左页是缩小复用的封面（`notebook-cover` 那套原样搬过来），右页是一页目录，用
  P1（茶渍）内页材质 + 4条占位目录随性排布 + 标题艺术字/正文清晰字体分层。
  只做了一页，**没有**做多痕迹页对比、没有做书脊分册标签——这两项还是
  `docs/BOOK_DESIGN.md` 步骤3 里没做完的部分，跳过了，不是做完了。
- `build-flip-transition-prototype.js` → `flip-transition-prototype.html`：
  **步骤5**，点击目录条目触发"哗啦啦翻过一叠纸"动效，取4张不同痕迹的内页材质
  错开快速翻过，总时长 0.7s（落在规格要求的 0.6–1s 区间），用假延迟
  （550–750ms 随机）模拟异步取全文内容，动画结束和内容到达两者时长故意做得
  接近，用来验证"内容比动画早到/晚到"两种情况下都不会让用户看到空白或跳变。

## 步骤5动效目前的坑 / 下一步

- **这段动效是假数据触发的**，用 `setTimeout` 模拟异步延迟。步骤4把真实文章
  数据和路由接上之后，这里要重新接线：把 `setTimeout(fakeLatency)` 换成真实的
  `fetch(slug)` 完成时机，动效本身（错开时间、旋转轨迹、总时长）不用大改，
  只是触发信号源要换。
- 还没问过站长这版动效的手感——时长、翻页轨迹、内容淡入方式都可能要调，
  站长看过后暂未给出具体反馈就要求先提交上传，**不代表定稿**。
- 只做了"点击进入"这一个方向，没做"返回目录"的对应动效（如果需要对称的
  反向动效，是步骤5的补充项，还没排期）。
