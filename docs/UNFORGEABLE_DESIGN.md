# 任务 B 补充：从"加扰动"到"什么才算真的难以复制" · 心路历程

> 这份文档记录的不是最终方案，是**一次判断过程**——为什么第一版尝试被推翻、
> 推翻的依据是什么。下一个接手者（人或 AI）**在动手写代码前先读这份**，
> 避免重新掉进同一个坑（下面第 3 节详细说是什么坑）。
> 和 `docs/CYANOTYPE_REDESIGN.md` 的关系：那份文档提议的方向是"从工程蓝图
> 转向蓝晒摄影工艺"，本轮站长明确说**不是**（见下），所以那份文档的具体
> 视觉方向没有被采纳，但它第 1 节"已跟站长确认的事实"依然有效，仍然要看。

---

## 1. 起点：站长要什么

站长的原话（本轮聊天）：

> 「就是一切不可被直接复制感」
> 「我只是想要修改我可以看见的所有视觉上的简单感，就像皮革和纸张背景我就很喜欢，
> 签名我也喜欢，但其余的完全就没有特色，一点没有」
> 「我怎么和你说你就瞎改，我怎么办啊」——针对"只说了线条就只改线条"的批评

明确了两件事：

1. **范围是全部，不是逐项点名**。站长不想一项项交代，AI 需要自己去找"哪些地方看着配套，
   实际是默认套路"，这是接手者的责任，不能等指令。
2. **皮革纹理（`tools/build-leather.js`）和品牌签名（`src/utils/brand.js` 的 `buildSignature`）
   是唯一两个站长明确认可"这就是我要的感觉"的东西**，后面所有判断都要拿这两个当参照系，
   而不是凭感觉猜。

## 2. 第一轮盘点：找出"假定制"

对照皮革/签名的质感，把全站前台过了一遍，找到的"看着配套、实际是默认套路"清单：

- 蓝图网格线 + 交点针孔（`body` 背景，纯 `linear-gradient` 等距重复）
- 卡片缝线（`.post-card::before`，`repeating-linear-gradient`，7px/12px 精确等距）
- 烫金分隔线（`.titleblock::after`、`footer::before`、`.post-article header::after`，三处同一条渐变直线）
- 标签 pill（`.article-tags`、`.tag-index-item .tag-count`、评论作者徽章）——全网通用 tag chip
- 按钮 `.btn`——纯色矩形 flat design
- 引用块装饰引号（`blockquote::before`）——字体自带的打字机双引号字符
- 分页箭头——直接写死 `&larr;`/`&rarr;` HTML 字符实体，零设计
- 高亮 `mark`、callout 提示框（GitHub/Notion 那套通用文档样式，跟蓝图/皮革概念脱节）
- 404 页面纯文字、`hr`/表格/sitemap 的默认 `dashed` 边框
- 书签丝带 `.pinned-label`——纯色渐变 + `clip-path`，站长没表态是否要动，先列出

这一步站长认可，问题出在下一步。

## 3. 第一次尝试，被推翻：给路径加随机扰动

样稿代码见 `experiments/unforgeable-linework/`（保留，不删，作为反面参照）：

- `build-sample.js`：网格线/针孔/缝线的"规则 vs 不规则"对比
- `build-elements-sample.js`：标签/按钮/引号/分页箭头的"规则 vs 不规则"对比

做法是给本来数学上精确的直线/路径的每个顶点叠一点 `mulberry32` seed 生成的随机偏移
（"手抖路径"），网格线不再绝对直，针脚长短不一，标签变成不规则四边形。

**站长看完样稿的反问：「你看你画的那几个图形，用的是不是还是普通的线条？」**

这句话戳穿的问题：**"给路径加随机抖动"本身就是一个已经被用滥的默认套路**——
跟网上"手绘草图风格"特效库（例如 rough.js 这类）做的是同一件事，网上教程一大把，
一点不比原来的 `linear-gradient` 难复制，甚至更容易被认出"这是套了个手绘特效库"。
把"不规则"当成了"原创"，但两者不是一回事：形状变得不整齐了，**生成逻辑的深度和难度完全没变**，
换汤不换药。

## 4. 真正的参照系：皮革和签名凭什么"难以复制"

重新拆解这两个站长认可的东西，发现它们靠的**不是同一种"难以复制"**：

- **皮革**（`tools/build-leather.js`）：难以复制靠的是**结构复杂度**——细胞噪声（Worley）
  决定粒面、多层值噪声叠毛孔纤维、高度场转法线、漫反射+高光光照模型、低频色斑，
  五六层独立系统叠在一起才出一张图。它是在**渲染一种材质的物理成因**，不是在装饰一条线；
  单拎出"加了随机数"这一件事根本不足以复刻它。
- **签名**（`src/utils/brand.js` 的 `buildSignature`/`guilloche`/`rosette`）：难以复制靠的是
  **它压根不是算法生成的**——是站长自己说过的"手工拟合的贝塞尔控制点"，一笔一笔调出来的
  真实原创图形，没有"配方"这回事，因为它不是从配方跑出来的。

结论：**"原创材质"（多层物理/结构模拟系统）和"原创图形"（真人手作，非公式套出来的）
是两条完全不同、但各自成立的路，"给现有形状叠随机数"两条都不沾边，是第三条假路。**

## 5. 现状与下一步（未定，待续）

站长确认接下来要走的是**原创图形 + 原创材质**这两条路（不是"加扰动"那条），
但具体怎么把第 2 节列出的那批"假定制"元素分别归到这两条路里，**还没有定案**，
是下一步要做的事。下一个接手者接着往下推进时：

- 先别急着写代码/出样稿，先想清楚某个具体元素该走哪条路，为什么；
- 如果想不出"结构复杂度"或"真人手作"任一条路怎么落地，**说明这个元素可能不值得
  单独做一套系统**，应该跟站长确认要不要换个完全不同的思路（这是本文档结尾前
  站长自己提出的备选问题，还没回答）；
- `experiments/unforgeable-linework/` 里的代码不要当作可以直接拿来用的方案，
  它的价值只是"记录了一次被否掉的尝试"。

## 6. 分类决定（2026-09-24 第三轮，已跟站长确认）

拿皮革和签名当尺子，把第 2 节"假定制"清单逐项归类。**站长原话："不用担心工程量，
我只要最好的"**——下面两处标了"工程量大"的选项已经拍板选重的那条，不要因为省事
选轻量方案。

### 归到"原创材质"——延伸皮革现有渲染管线（细胞噪声→高度场→法线→光照），不是另起系统

| 元素 | 具体做法 |
|---|---|
| 网格线 + 针孔 | 不是"直线加抖动"，模拟"墨水在覆蜡纸上吸墨不均 + 同一把尺子反复使用留下的相关性瑕疵"——整条线的偏差要互相关联（同一把尺子的系统性弯曲），不是每条线独立抖动 |
| 缝线 | **★工程量大，已确认要做**：复用皮革的高度场/法线/光照管线，把线做出真实的圆柱体截面 + 高光，而不是现在的 2D 虚线渐变 |
| 烫金分隔线 | 复用皮革光照管线，换一套金属反射参数模拟金箔烫印的压印深度 + 反射 |
| 标签 pill、按钮、书签丝带、评论徽章 | 不需要新材质，是"皮革材质裁成不同形状 + 缝边"，直接复用现成系统 |
| callout 提示框、`hr`、表格/sitemap 分隔线 | 网格线的"墨水+纸"材质做出来后，直接套小尺度版本，不单独立项 |

### 归到"原创图形"——像签名一样先手工/派生做出来，不是跑算法生成

| 元素 | 具体做法 |
|---|---|
| 引用装饰引号 | 工作量小，手工画一个笔触引号，固定复用，不需要运行时生成 |
| 分页箭头 | **★已确认要做**：从 `src/utils/brand.js` 里已有的 `rosette()` 罗盘花饰派生，跟签名是同一套视觉词汇的延伸，不是发明新图形语言 |

### 可能不单独立项

| 元素 | 说明 |
|---|---|
| 高亮 `mark` | 体量太小，套材质/图形系统都小题大做；该换的可能是隐喻本身（"荧光笔"→"红蓝铅笔标注"这种更贴"图纸"概念的说法），实现仍简单，但概念对了就不算默认套路 |
| 404 页面 | 不属于以上任何一条，缺的是一张手工小插画，工作量比其他项都大，单独排期，不塞进这一轮 |

### 下一步

按上表开始动手，顺序未定。缝线（圆柱体截面）和分页箭头（`rosette()` 派生）是
两个已经明确"要做重的那版"的项，优先级可以放前面，因为技术路径已经拍板，
不会像标签/按钮那样还要先等材质系统那条线做完才能套用。
